# orchestra-mcp/pack-rust-engine

Rust engine skills and agents for Tonic, Tree-sitter, and Tantivy

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-rust-engine
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-rust-engine")
```

## Contents

| Type | Names |
|------|-------|
| Skills | rust-engine |
| Agents | rust-engineer, qa-rust |
| Hooks | None |
